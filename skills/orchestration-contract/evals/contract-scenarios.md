# Contract scenarios

These cases specify transitions for `orchestration-contract`; they are not recorded executions.
Use an existing qualified evaluation interface when available. Cross-host activation, composed
implementation and bug runs require separate observed qualification. No runner or gate is added here.

For each case, inspect the selected request class, owner, returned state, next action, allowed
effects and retained evidence or budget. A specialist's report is an input to inspect, not proof.

| Case                        | Input and observed step result                                                                                                                                                       | Expected transition                                                                                                                                                                                                      |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Plan alone                  | “Plan invoice export; do not implement.” Design returns a usable plan with settled decisions.                                                                                        | Owner delivers the plan and its limits; no edits, commits or implementation launch.                                                                                                                                      |
| Full request                | “Plan then implement invoice export, verify and commit locally; no push.” Design returns the same usable plan.                                                                       | Owner continues authorized implementation, existing checks and local commit; no new plan approval, push or PR. A green unit test alone cannot finish the request.                                                        |
| Analysis alone              | “Explain the failing export; do not fix it.” Diagnosis returns a cause and reproduction evidence.                                                                                    | Owner returns the analysis and evidence; no repair.                                                                                                                                                                      |
| Bug repair                  | “Fix the failing export.” Diagnosis returns only a plausible cause; the reproducing environment is unavailable.                                                                      | Hypothesis remains unverified; prepare the probe and progress independent work. No confirmed-cause or verified-repair claim; missing essential execution blocks dependent repair.                                        |
| Specialist return           | During a full task a TDD delegate returns “done”, a changed diff and one passing test.                                                                                               | Original owner inspects the delta and evidence, then continues remaining task checks and authorized delivery. Delegate does not start another orchestrator or final review loop.                                         |
| Recoverable failure         | A relevant check fails with observations refuting the proposed cause; investigation has budget left.                                                                                 | Return evidence to diagnosis rather than repeating the same correction. Preserve elapsed budget; rerun affected checks after a supported repair. A design contradiction instead returns to design.                       |
| Required evidence           | Implementation is written; required validation or an explicitly requested review cannot run.                                                                                         | Affected stage remains blocked/incomplete, regardless of other green checks. State the missing capability. An unrequested optional review does not become a prerequisite.                                                |
| Invalid return              | Delegate times out or returns an empty report after possibly changing files.                                                                                                         | Inspect candidate contents before any retry. Keep the step unfinished; no acceptance from an empty result or competing writer.                                                                                           |
| Decision and partial block  | A reserved retention decision is pending; a documentation correction has no code or architectural dependency on it.                                                                  | Ask the concrete policy question through clarification, retain it as pending and continue the independently authorized correction. Silence and tests cannot approve retention.                                           |
| Discoverable fact           | A skill asks which existing command validates the repository; the command is in its package manifest.                                                                                | Owner reads the manifest and resolves the fact without a user questionnaire.                                                                                                                                             |
| Resume after changes        | HEAD matches the handoff, but an unstaged artifact and a check input changed. One correction pass and twelve minutes of a fifteen-minute investigation budget were already consumed. | Reconcile actual contents, keep decisions still applicable, invalidate affected evidence and revalidate dependent steps. Retain one consumed pass and three remaining minutes; do not replay unrelated completed stages. |
| Exhausted or lost history   | A continuation has exhausted its specialist's two correction passes, or cannot recover whether the last pass was consumed.                                                           | Do not start another correction loop. Preserve the candidate and report exhaustion or the unverifiable counter; independent work may continue.                                                                           |
| PR repair versus local work | An explicit PR repair already has a `pr-fix` journal and owner. Another specialist returns a finding.                                                                                | Original repair owner consumes it within its existing budget and checkpoints; no parallel local repair loop. An ordinary feature on a PR branch alone does not activate `pr-fix`.                                        |
| Uncertain external action   | A previously authorized publication times out; remote state is unknown at resumption.                                                                                                | Inspect remote state before retrying. Reuse a created artifact; perform only the missing safe operation within the existing authority. No duplicate creation or inferred publication consent.                            |
| Host and cost               | A small composed declarative task runs without a subagent API, host-specific Skill tool, tracker or independent-review requirement.                                                  | Apply the contract directly with available facilities and native validation. Do not install tooling, require another model, add review or introduce a heavy plan.                                                        |

The ownership and invalid-return cases exercise the adapted poteto-mode interaction. Plan boundaries
and recovery reflect the architect and plan comparisons. Full-result and dependency-ready partial
progress cases exercise the implement and implement-spec adaptations. The reference table in the
skill records the excluded effects and cost; these expected results do not demonstrate host behavior.
