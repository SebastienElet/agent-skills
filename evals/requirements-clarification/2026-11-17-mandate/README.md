# Mandate and reserved decisions

`cases.json` contains synthetic application/forge cases and their executable oracles.
`conditions.json` freezes the common instructions and the baseline, deletion and reduction
alternatives. The `*-final` variants restore the general speculative-isolation guard identified
in review. `protocol.json` records the planned observations, controls, environment and limits.

Read `summary.json`, the `observations.json` index and its individual records together. An executable oracle
success does not grade a conversation question, proposal timing or the meaning of a posted note.
Those dispositions come from manual inspection of the retained events and source snapshots.
Pre-correction observations, invalid preparation attempts and unexecuted withdrawn work remain
separate from the final comparison.

## Replay

1. Select one case and condition. In a new disposable Git workspace, materialize the case's
   `files`, then assemble `AGENTS.md` using the exact common instructions, selected workflow bodies
   and assembly order in `conditions.json`. Run the case's trusted setup.
2. Use a fresh private home and Codex home with independently available authentication; exclude
   credentials from retained artifacts and remove that home after the run. Invoke the recorded
   native CLI command with new workspace paths and the unchanged case prompt. Keep the explicit
   instruction budget, model, effort, network policy, runtime versions and bounded concurrency.
   The old repository-run preparation attempts did not load the complete instructions automatically
   and are not a qualified replacement for this invocation.
3. Capture JSONL events and a source snapshot before oracle execution. Restore the original
   `feature.test.mjs` from the case, then execute its oracle outside the agent's writable workspace.
   Keep nonzero agent exits, incomplete turns, provider errors, timeouts and unavailable runtimes
   distinct from observed application failures. `oracle-witnesses.json` retains independent
   negative witnesses for the narrow executable boundaries.
4. Inspect actual questions, executed tests, proposal ordering, shared effects and forge note
   calls against the protocol's expectations. For a scope split, read both posted notes for the
   decision, reason and revisit condition. Do not infer these outcomes from the oracle exit alone.

This is explicit composed-instruction application on synthetic services. It does not qualify
installed skill discovery, remote forge behavior, a complete development workflow, other hosts
or a statistical performance improvement. Historical observations retain their own identities;
a later source correction does not update the instructions that an earlier session received.
